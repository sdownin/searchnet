# SaoMNK Formal Proofs

This directory contains the formal mathematical proofs and supporting materials
for the SaoMNK framework.

## Files

- **saomnk_nk_equivalence_proof.tex** -- Formal proofs of Theorems 1-3
  (Reduction, Generalization, Approximation) establishing NK as a special case
  of SaoMNK.

- **saomnk_online_appendix_master.tex** -- Master online appendix organizing
  all formal results.

- **saomnk_proof_tutorial.Rmd** -- Interactive R tutorial walking through the
  three theorems with computational verification.

## Access from R

```r
# List all proof files
searchnet_proof()

# Open a specific file
searchnet_proof("saomnk_proof_tutorial.Rmd")
```
