## How to Read This Table

Each row is one logical step. The columns are:

- **Step**: Sequential identifier (letter = part, number = order within part).
- **Type**: Axiom, Definition, Assumption (Restriction), Lemma, Theorem, Proposition, Corollary, Remark, or Example.
- **Name**: Short identifier.
- **Statement**: The formal claim in math notation AND plain English.
- **Proof / Justification**: How this step is derived (references to prior steps, external results, or computational verification).
- **Source**: Which document contains the full proof or definition.
- **Depends On**: Which prior steps this step requires.

**Notation conventions.** Vectors are bold lowercase (b, x). Matrices are bold uppercase (B, A, E). Element-wise (Hadamard) product is written with the circled-dot symbol. The power key PK(N) = (2^{N-1}, 2^{N-2}, ..., 2^0). All log-odds are natural logarithms.

## PART A: FOUNDATIONS (Axioms and Primitive Definitions)

These are the basic building blocks. They require no proof; they are either
stipulated by construction or imported from established literature.

| Step | Type | Name | Statement | Justification | Source | Depends On |
|------|------|------|-----------|---------------|--------|------------|
| A1 | Axiom | Binary decision space | Each actor i in {1,...,M} has a binary decision vector b_i in {0,1}^N representing which of N components they hold. In plain English: every actor makes a yes/no decision on each of N possible components. | By construction --- the bipartite network is defined as binary ties between actors and components. | EqProof, Def 3 | --- |
| A2 | Axiom | Bipartite state matrix | The system state is B in {0,1}^{M x N} where row i is actor i's configuration b_i. In plain English: the full state of the system is a binary matrix with one row per actor and one column per component. | Stacks A1 for all M actors into a single matrix. | EqProof, Def 3 | A1 |
| A3 | Axiom | Finite state space | The state space is S = {0,1}^{M x N}, which has cardinality 2^{MN}. All transitions occur within this finite set. | Finite product of finite binary vectors. | EqProof, Def 3 | A2 |
| A4 | Definition | NK Landscape | A tuple (N, K, A, {f_d}_{d=1}^N) where: (i) N is the number of binary components; (ii) K in {0,...,N-1} is the epistasis parameter; (iii) A in {0,1}^{N x N} is the epistasis matrix with A_{dd}=1 and sum_j A_{dj} = K+1 for all d; (iv) f_d : {0,1}^{K+1} -> [0,1] is the component payoff function, drawn i.i.d. Uniform(0,1). Fitness: W(x) = (1/N) sum_{d=1}^{N} f_d(x_{N(d)}), where x_{N(d)} is the sub-vector of x restricted to the epistatic neighborhood N(d) = {j : A_{dj} = 1}. In plain English: each component's payoff depends on itself and K other components. Total fitness is the average of all component payoffs. | Standard definition from Kauffman (1993). The epistasis matrix encodes which components affect each other. | Kauffman93; EqProof, Def 1 | --- |
| A5 | Definition | Epistasis matrix | A in {0,1}^{N x N} with A_{dd}=1 for all d (every component depends on itself) and sum_j A_{dj} = K+1 for all d (each component depends on exactly K others plus itself). In plain English: a binary matrix that says "component d's payoff depends on component j" whenever A_{dj} = 1. | Sub-component of A4. | Kauffman93 | A4 |
| A6 | Definition | Epistatic neighborhood | N(d) = {j : A_{dj} = 1}, with |N(d)| = K+1. In plain English: the set of components that affect component d's payoff, including d itself. | Derived from A5. | Kauffman93 | A5 |
| A7 | Definition | Component payoff function | f_d : {0,1}^{K+1} -> [0,1], with values drawn i.i.d. Uniform(0,1). In plain English: for each component d, there is a lookup table mapping every possible configuration of the K+1 epistatic bits to a random payoff between 0 and 1. | Part of the NK tuple (A4). The randomness of the landscape is the source of complexity. | Kauffman93 | A4, A6 |
| A8 | Definition | NK Fitness function | W(x) = (1/N) sum_{d=1}^{N} f_d(x_{N(d)}). In plain English: total fitness is the average payoff across all N components, where each component's payoff depends on the configuration of its epistatic neighborhood. | Central equation of the NK model. | Kauffman93; EqProof, Eq 1 | A4, A6, A7 |
| A9 | Definition | Power key | PK(N) = (2^{N-1}, 2^{N-2}, ..., 2^0). The index function: r_d(x) = sum_j x_j * A_{dj} * PK_j + 1. In plain English: a positional weighting vector that converts a binary sub-vector into an integer index for looking up the payoff table. The "+1" converts from 0-based to 1-based indexing. | Computational device for efficient payoff lookup. Used identically in both NK and SaoMNK implementations. | Tutorial; EqProof, Eq 3 | A4 |
| A10 | Definition | NK Landscape matrix | NK_land in R^{2^N x N}. Entry NK_land[r, d] gives the payoff for component d when the masked configuration indexes row r. In plain English: instead of N separate payoff tables, SaoMNK stores all component payoffs in a single matrix indexed by the power key. | Equivalent storage format for {f_d}. The Tutorial demonstrates that NK_land[sum(x * A_{d.} * PK) + 1, d] = f_d(x_{N(d)}) for all x and d. | Tutorial | A7, A9 |
| A11 | Definition | NK Adaptive Walk | A sequence x^(0), x^(1), ... defined by: (i) x^(0) drawn uniformly from {0,1}^N; (ii) at each step, a component d is selected and the flip x^(t) XOR e_d is evaluated; if W(x^(t) XOR e_d) > W(x^(t)), then x^(t+1) = x^(t) XOR e_d, otherwise x^(t+1) = x^(t); (iii) terminates at a local optimum. The greedy variant selects d* = argmax_d [W(x^(t) XOR e_d) - W(x^(t))]. In plain English: a hill-climbing search that flips one bit at a time, always accepting improvements and stopping when no single-bit flip improves fitness. | Standard NK search dynamics. | Kauffman93; EqProof, Def 2 | A8 |

## PART B: THE SAOM-NK MODEL (Definitions 1--5)

These definitions extend the NK foundations to the multi-actor, network-embedded,
stochastic-choice setting.

| Step | Type | Name | Statement | Justification | Source | Depends On |
|------|------|------|-----------|---------------|--------|------------|
| B1 | Definition | SaoMNK Model (Def 3) | A tuple (M, N, E, {f_d}_{d=1}^N, theta, beta) where: (i) M in N is the number of actors; (ii) N in N is the number of binary components; (iii) E in {0,1}^{N x N} is the epistasis matrix with E_{dd}=1; (iv) {f_d} are component payoff functions as in NK; (v) theta in R^p is the vector of SAOM effect parameters; (vi) beta > 0 is the logit precision parameter. State space S = {0,1}^{M x N}. In plain English: the SaoMNK model is an NK landscape plus multiple actors, network effects, and stochastic choice. | Extension of A4 to the multi-actor, network-embedded setting. Adds actors (M), network parameters (theta), and a rationality dial (beta). | EqProof, Def 3; Theory, Def 3; CD2026, Def 3 | A1--A10 |
| B2 | Definition | SaoMNK Utility (Def 4) | u_i(b_i; B_{-i}, E) = [NK component] + [SAOM statistics] = sum_{d=1}^{N} b_{id} * f_d(b_i (Hadamard) E_{d.}) + sum_{k=1}^{p} theta_k * s_k(b_i, B). The first term is the epistatic fitness contribution, where the Hadamard product b_i (Hadamard) E_{d.} masks actor i's configuration by the epistatic neighborhood of component d. The second term captures endogenous network effects (density, popularity, scope, etc.) weighted by structural parameters theta_k. In plain English: each actor's utility has two parts --- how well their component choices fit the landscape (NK part), and how their choices interact with other actors' choices (network part). | The two-part utility is the core innovation: it nests NK fitness within the SAOM framework. | EqProof, Def 4; Theory, Def 2; CD2026, Def 4 | A7, A9, A10, B1 |
| B3 | Definition | Power key indexing in SaoMNK | f_d(b_i (Hadamard) E_{d.}) = NK_land[sum_j b_{ij} * E_{dj} * PK(N)_j + 1, d]. In plain English: to compute component d's payoff for actor i, mask actor i's configuration by the epistasis row for d, convert to an integer using the power key, and look up the payoff in the landscape matrix. | Algebraic restatement of how the Hadamard masking operation maps to the landscape matrix. This is the same lookup as standard NK but embedded in the full N-bit power key. | EqProof, Eq 3; Tutorial | A9, A10, B2 |
| B4 | Definition | SAOM Statistics | The network statistics s_k(b_i, B) include: (a) s_density(b_i) = sum_j b_{ij} [total number of ties actor i holds]; (b) s_outAct(b_i) = (sum_j b_{ij})^2 [squared scope --- penalizes/rewards breadth]; (c) s_inPop(b_i, B) = sum_j b_{ij} * (sum_m b_{mj} + 1) [preference for popular components --- actor i gets more utility from components that many other actors also hold]; (d) s_cycle4(b_i, B) = (1/2) * [diag(BB')^2 * BB']_{ii} [four-cycle closure in the bipartite graph --- captures indirect structural coupling]; (e) s_XWX(b_i, W) = sum_j b_{ij} * sum_k w_{jk} * b_{ik} [exogenous inter-component complementarity weighted by matrix W]. In plain English: these are summary statistics of the bipartite network B that capture different dimensions of how actors' choices relate to each other and to the component structure. | Standard RSiena effect specifications adapted for bipartite networks. Each statistic captures a distinct dimension of network structure. | Snijders01; EqProof, Eqs 4--7; Theory, Table 1 | A2, B1 |
| B5 | Definition | Ministep Dynamics (Def 5) | The SaoMNK model evolves as a continuous-time Markov chain (CTMC). At each ministep: (i) actor i is selected with rate lambda_i > 0; (ii) actor i evaluates all single-tie changes b_i XOR e_j for j in {1,...,N}, plus the status quo b_i; (iii) the choice follows a multinomial logit: P(flip j | i) = exp(beta * Delta_u_{ij}) / (1 + sum_{k=1}^{N} exp(beta * Delta_u_{ik})), where Delta_u_{ij} = u_i(b_i XOR e_j; B_{-i}, E) - u_i(b_i; B_{-i}, E). The 1 in the denominator represents the option of no change. In plain English: actors take turns. When it is your turn, you look at every possible single-component change (add one, drop one, or do nothing) and choose probabilistically, with better options being more likely. | McFadden (1974) conditional logit embedded in a CTMC. The SAOM architecture (Snijders, 1996) provides the rate-function / objective-function separation that maps directly onto NK's local search. | McFadden74; Snijders01; EqProof, Def 5; CD2026, Def 5 | B2, B4 |
| B6 | Definition | Choice set | C_i = {(add, j) : b_{ij}=0} union {(drop, j) : b_{ij}=1} union {pass}. In plain English: at each ministep, actor i can add any component it does not hold, drop any component it holds, or do nothing. | Exhaustive enumeration of feasible single-tie changes. There are exactly N+1 options (N possible flips plus status quo). | --- | B1, B5 |
| B7 | Definition | Marginal utility of a flip | Delta_u_{ij} = u_i(b_i XOR e_j; B_{-i}, E) - u_i(b_i; B_{-i}, E). In plain English: the change in actor i's utility if they flip their tie to component j. Positive means the flip is beneficial; negative means it is costly. | Difference of B2 evaluated at the current state and the flipped state. | --- | B2 |

## PART C: NK AS SPECIAL CASE (Theorem 1 --- Reduction)

This part proves that the standard NK model is a degenerate special case of SaoMNK,
recoverable by imposing five restrictions.

| Step | Type | Name | Statement | Justification | Source | Depends On |
|------|------|------|-----------|---------------|--------|------------|
| C1 | Restriction | R1: Single actor | M = 1. The state space reduces from {0,1}^{M x N} to {0,1}^N. The bipartite matrix B reduces to a single row vector b_1 = x in {0,1}^N. In plain English: there is only one decision-maker. | Restriction imposed on B1. Eliminates all multi-actor aspects. | EqProof, Thm 1 | B1 |
| C2 | Restriction | R2: Epistasis alignment | E = A (the SaoMNK epistasis matrix equals the NK interaction matrix, with K+1 ones per row). In plain English: the epistatic structure is identical in both models. | Restriction imposed on B1. Ensures the component payoff lookup is identical. | EqProof, Thm 1 | A5, B1 |
| C3 | Restriction | R3: No network effects | theta = 0 (all SAOM effect parameters set to zero). In plain English: the network-structural part of the utility function is switched off entirely. | Restriction imposed on B2. Eliminates the entire second sum in the utility function. | EqProof, Thm 1 | B2, B4 |
| C4 | Restriction | R4: Deterministic greedy search | beta -> infinity (logit precision diverges). In the limit, P(flip j) -> 1 if j = argmax Delta_u and Delta_u_j > 0; P(flip j) -> 0 otherwise. P(pass) -> 1 if all Delta_u_j <= 0. In plain English: the actor always picks the single best-improving change, with no randomness. | Restriction imposed on B5. Recovers deterministic greedy choice from the logit. | EqProof, Thm 1 | B5 |
| C5 | Restriction | R5: Constant rate | lambda_i = constant (uniform selection probability). With M=1, the rate is irrelevant because there is only one actor to select. In plain English: selection is uniform. | Restriction imposed on B5. | EqProof, Thm 1 | B5, C1 |
| C6 | Lemma | Lemma 1: Payoff Equivalence | Under R1--R3, the SaoMNK utility reduces to the NK fitness (up to scaling by N): W(x) = (1/N) * u(x; A). Specifically: (1) Under R1, B -> b_1 = x. (2) Under R3, the SAOM statistics term vanishes: sum_k theta_k * s_k = 0. (3) Under R2, the masking x (Hadamard) E_{d.} = x (Hadamard) A_{d.} selects exactly the bits in N(d). (4) Therefore u(x; A) = sum_d x_d * f_d(x_{N(d)}) = N * W(x). In plain English: when there is one actor, no network effects, and identical epistasis matrices, the SaoMNK utility function is just N times the NK fitness. The 1/N factor is a normalization that does not affect ordinal rankings. | Direct algebraic substitution. With M=1, no B_{-i} terms exist. With theta=0, all network statistics vanish. The Hadamard masking with E=A reproduces the NK sub-vector lookup via the power key (see B3). The Tutorial verifies this computationally for all 2^N configurations. | EqProof, Lemma 1; Tutorial, Sec 2; CD2026, Lemma 1 | C1, C2, C3, B2, B3 |
| C7 | Proof step | Index equivalence detail | f_d(x (Hadamard) A_{d.}) = NK_land[sum_j x_j * A_{dj} * PK_j + 1, d]. Since A_{dj} = 0 for j not in N(d), the non-epistatic bits contribute zero to the index sum. The resulting integer index is identical to the standard NK lookup of f_d(x_{N(d)}). In plain English: masking non-epistatic bits to zero before computing the power-key index produces the exact same table lookup as extracting only the epistatic bits. | Algebraic: x_j * A_{dj} = 0 when j not in N(d), so those bits are zeroed. The remaining bits produce the same index as the K+1-bit sub-vector. | Tutorial; EqProof, proof of Lemma 1 | A9, A10, C6 |
| C8 | Lemma | Lemma 2: Dynamic Equivalence | Under R1--R5, the SaoMNK ministep dynamics produce the same sequence of states as the NK greedy adaptive walk. Proof outline: (1) Under R1, only one actor exists; the rate function is trivial. (2) At each ministep, the actor evaluates all N possible flips. By C6, Delta_u_j = N * [W(x XOR e_j) - W(x)], so ordinal rankings are preserved. (3) Under R4 (beta -> infinity), the logit converges to: P(flip j) = 1 if j = argmax Delta_u_j and Delta_u_{j*} > 0; P(pass) = 1 if all Delta_u_j <= 0. (4) This is exactly the NK greedy adaptive walk (A11). Under R5 with uniform component selection, it yields the random-order adaptive walk. Both are standard NK dynamics. In plain English: with one actor and perfectly rational greedy choice, the SaoMNK ministep process makes the exact same sequence of decisions as the NK adaptive walk. | The logit limit follows from: lim_{beta->inf} exp(beta * Delta_u_j) / (1 + sum_k exp(beta * Delta_u_k)) = 1 if j=argmax and max > 0, else 0. Uniqueness of argmax holds with probability 1 under i.i.d. Uniform payoffs. The Tutorial verifies this computationally with 200 parallel walks from random starting points, all producing identical trajectories. | EqProof, Lemma 2; Tutorial, Sec 2; CD2026, Lemma 2 | C1, C4, C5, C6, B5, A11 |
| C9 | Theorem | **Theorem 1: Reduction** | The standard NK model (A4, A11) is a degenerate special case of the SaoMNK model (B1--B5). Specifically, the NK landscape and its adaptive walk are recovered exactly from SaoMNK under restrictions R1--R5. Formally: NK subset SaoMNK. In plain English: set five switches to their extreme positions (one actor, matching epistasis, no network effects, greedy search, constant rate), and SaoMNK collapses exactly to NK. Every NK result is automatically a special case of SaoMNK. | Combines Lemma 1 (C6, payoff equivalence) and Lemma 2 (C8, dynamic equivalence). Both the static fitness function and the dynamic search process are recovered. | EqProof, Thm 1; CD2026, Thm 1; Theory, Thm 1 | C6, C8 |
| C10 | Remark | Computational verification | The payoff equivalence (C6) and dynamic equivalence (C8) can be verified directly in the SaoMNK codebase. The function calc_fit() computes: NK_land[sum(Current_position * inter_m[d, ] * Power_key) + 1, d], which implements B3. Setting inter_m = A and Current_position = x gives the NK payoff lookup. The Tutorial runs 200 walks from random starts and confirms max |f_NK - f_SaoMNK| < 10^{-15} (machine precision). | Computational verification supplements the algebraic proof. | Tutorial; EqProof, Remark 1 | C6, C8 |

## PART D: SAOMNK STRICTLY EXTENDS NK (Theorem 2 --- Generalization)

This part proves that SaoMNK can produce behavior impossible in any NK model,
along three independent dimensions.

| Step | Type | Name | Statement | Justification | Source | Depends On |
|------|------|------|-----------|---------------|--------|------------|
| D1 | Lemma | Lemma 3: Landscape Endogeneity | When M >= 2 and theta_inPop != 0, actor i's effective landscape W_tilde_i(b_i) := u_i(b_i; B_{-i}, E) depends on B_{-i}. Any change in actor j's configuration (j != i) generically alters actor i's landscape. Formally: for all j != i, there exist b_j, b_j' such that W_tilde_i(b_i | b_j) != W_tilde_i(b_i | b_j'). In plain English: when there are multiple actors and the popularity effect is active, changing what one actor does changes the landscape that every other actor faces. | Fix actor i with b_{id}=1 for some component d. Let actor j have two configurations differing only in component d: b_{jd}=0 vs b_{jd}'=1. Then s_inPop(b_i, B') - s_inPop(b_i, B) = b_{id} * 1 = 1 != 0, so u_i changes by theta_inPop != 0. | EqProof, Lemma 3; CD2026, Lemma 3 | B2, B4 |
| D2 | Lemma | Lemma 4: Search Precision Spectrum | For any beta in (0, infinity) and any configuration x that is not a global optimum, the SaoMNK dynamics with M=1, theta=0 assign positive probability to EVERY single-bit flip, including fitness-decreasing ones. In contrast, the NK adaptive walk assigns zero probability to fitness-decreasing flips. Formally: P(flip j) = exp(beta * Delta_u_j) / (1 + sum_k exp(beta * Delta_u_k)) > 0 for ALL j, even when Delta_u_j < 0. In plain English: with finite precision (beta < infinity), the actor can make mistakes --- choosing moves that lower fitness. NK search never makes mistakes. | exp(beta * Delta_u_j) > 0 for all finite beta and all Delta_u_j in R. The denominator is finite and positive. Therefore the probability is strictly positive. The NK adaptive walk sets P = 0 whenever Delta_u_j <= 0 by definition. | EqProof, Lemma 4; CD2026, Lemma 4 | B5, C4 |
| D3 | Example | Dimension (a): Multi-actor | With M=2, theta=0, beta -> infinity: two independent NK adaptive walks on the same landscape. The state space is {0,1}^{2N} vs {0,1}^N. Even without interaction, the system has 2 simultaneous walkers. This is already outside the single-agent NK framework. In plain English: two firms searching the same landscape is not the same as one firm. | With M >= 2, the state space grows from 2^N to 2^{MN} = (2^N)^M. Even the trivial case (no interaction) lies outside single-agent NK because the system tracks M independent configurations simultaneously. | EqProof, Example 1; CD2026 | B1, C9 |
| D4 | Example | Dimension (b): Endogenous landscape | With M=2, theta_inPop = 1, beta -> infinity: actor 1's landscape changes whenever actor 2 changes a tie. If actor 2 connects to component d, actor 1's utility from holding d increases by 1. This cannot be captured by ANY single-actor NK model, because NK fitness W(x) depends only on x and the fixed payoff table --- it has no mechanism for another agent's state to enter the payoff function. In plain English: the landscape reshapes itself as actors move. | By Lemma 3 (D1). The inPop term creates a direct dependence of actor i's utility on all other actors' configurations. This is fundamentally different from "coupled landscapes" in Siggelkow & Rivkin (2005), where coupling is exogenous. | EqProof, Example 2; CD2026 | D1 |
| D5 | Example | Dimension (c): Bounded rationality | With M=1, theta=0, beta=1: the SaoMNK dynamics assign positive probability to fitness-decreasing moves (by Lemma 4). No parameterization of the NK adaptive walk can reproduce this, because NK search is deterministic. In plain English: the actor can make mistakes and explore sub-optimal configurations. NK never allows this. | By Lemma 4 (D2). At beta=1, P(flip j) > 0 for all j, including those with Delta_u_j < 0. The NK walk assigns P = 0 to all Delta_u_j <= 0. | EqProof, Example 3; CD2026 | D2 |
| D6 | Theorem | **Theorem 2: Generalization** | SaoMNK strictly extends NK along three independent dimensions: (a) multi-actor interaction (M > 1); (b) endogenous landscape co-evolution (theta != 0); (c) bounded rationality (beta < infinity). Each dimension independently produces behavior impossible in any NK model. Formally: NK strictly-subset SaoMNK. In plain English: SaoMNK can do everything NK can do (Theorem 1), plus three families of things NK cannot. | Each dimension independently generates behavior outside NK (D3, D4, D5). Independence: each example uses only one relaxation of the five restrictions. Combined with Theorem 1 (C9), which shows NK subset SaoMNK, the containment is strict. | EqProof, Thm 2; CD2026, Thm 2; Theory, Thm 2 | C9, D3, D4, D5 |

## PART E: NK PAYOFF APPROXIMATION (Theorem 3)

This part establishes that any NK landscape can be reproduced (exactly or to
arbitrary precision) within the SaoMNK framework. Three independent proof
strategies are given.

| Step | Type | Name | Statement | Justification | Source | Depends On |
|------|------|------|-----------|---------------|--------|------------|
| E1 | Theorem | **Theorem 3: Approximation** | For any NK landscape (N, K, A, {f_d}), there exists a parameterization of the SaoMNK model that reproduces the NK payoff structure to arbitrary precision. In plain English: for any NK landscape you can dream up, there is a way to set SaoMNK's parameters so that it produces the same fitness values. | Established via three independent proof strategies (E2, E5, E8), each sufficient on its own. | EqProof, Thm 3; CD2026, Thm 3; Theory, Thm 3 | E4, E7, E11 |
| E2 | Proposition | Prop 1: Constructive Existence via Dummy Covariates | For any NK landscape (N, K, A, {f_d}), there exists a set of N * 2^{K+1} dyadic covariates and corresponding SaoMNK parameters that EXACTLY reproduce the NK fitness function. In plain English: we can encode every entry of every NK payoff table as a separate covariate in SaoMNK, achieving perfect reproduction. | See proof in E3--E4. | EqProof, Prop 1; CD2026, Prop 3a | A4 |
| E3 | Proof step | Dummy covariate construction | For each component d and each of the 2^{K+1} configurations c_l of the epistatic bits N(d), define a binary (dummy) dyadic covariate: w_{dl}(x) = 1 if x_{N(d)} = c_l, 0 otherwise. Set the corresponding parameter alpha_{dl} = f_d(c_l) (the NK payoff value for that configuration). ## PART F: CONVERGENCE AND EQUILIBRIUM (Theorem 4 --- SAOM-QRE)

This part establishes that the SaoMNK CTMC has a well-defined stationary
distribution, and that this distribution is a Quantal Response Equilibrium.
The logical chain is: Potential Game (F1--F2) -> Blume's Theorem (F3--F5) ->
SAOM-QRE (F6--F7).

| Step | Type | Name | Statement | Justification | Source | Depends On |
|------|------|------|-----------|---------------|--------|------------|
| F1 | Definition | Potential Game | A game Gamma is an exact potential game if there exists a function Phi : X -> R such that u_i(a'_i, x_{-i}) - u_i(a_i, x_{-i}) = Phi(a'_i, x_{-i}) - Phi(a_i, x_{-i}) for all players i, all strategy pairs a_i, a'_i. In plain English: a potential game is one where every player's gain from changing strategy equals the change in a single global "score" function. | Definition from Monderer & Shapley (1996). Key property: pure Nash equilibria correspond to local maxima of Phi. | MonShap96; Blume | --- |
| F2 | Definition | Gibbs measure (Boltzmann distribution) | For a potential game with potential Phi and precision parameter beta > 0, the Gibbs measure is: pi_beta(x) = exp(beta * Phi(x)) / Z(beta), where Z(beta) = sum_{x'} exp(beta * Phi(x')) is the partition function (normalizing constant). In plain English: the Gibbs measure assigns probability to each state proportional to the exponential of its "score." High-score states get much more probability, especially when beta is large. | Standard definition from statistical mechanics, adapted to game theory by Blume (1993). The sign convention is positive (maximizing utility) rather than negative (minimizing energy). | Blume93; Blume | F1 |
| F3 | Lemma | SAOM is a potential game | SAOMs with additive utility and appropriate symmetry conditions admit a potential function Phi(B) = sum_k theta_k * S_k(B), where S_k is a global statistic. | F4 | Definition | Quantal Response Equilibrium (QRE) | A logit QRE is a probability distribution sigma over strategy profiles where each player's randomization is consistent with logit best response to the others' randomized strategies: sigma_i(a_i) proportional to exp(beta * E_{sigma_{-i}}[u_i(a_i, x_{-i})]). In plain English: every player is choosing randomly, but better options are more likely. | F5 | Theorem | Blume's Theorem (Logit-Gibbs Convergence) | For a finite potential game with potential function Phi, if players revise strategies via asynchronous logit best response with rationality parameter beta > 0, then the induced Markov chain is: (1) ergodic (every state is reachable from every other state), and (2) has a unique stationary distribution equal to the Gibbs measure: pi_beta(x) = exp(beta * Phi(x)) / Z(beta). | F6 | Proof step | Chain of identification | (1) SaoMNK uses logit choice (B5). (2) Under appropriate symmetry conditions, SaoMNK is a potential game (F3). In plain English: the SaoMNK simulation converges to a QRE --- a well-understood game-theoretic equilibrium concept. | Logical chain connecting the four prior results. | Blume; EqProof (Discussion) | B5, F3, F4, F5 |
| F7 | Theorem | **Theorem 4: SAOM-QRE Equivalence** | The stationary distribution of the SaoMNK CTMC with logit choice is a logit QRE. (3) Independence from initial conditions: every starting configuration converges to the same pi_beta. (4) Computability: the distribution has the known Gibbs form. (5) Limiting behavior: as beta -> infinity, pi_beta concentrates on the Nash equilibria (potential-function maxima); as beta -> 0, pi_beta approaches the uniform distribution. In plain English: the SaoMNK simulation always converges, it converges to the same thing regardless of starting point, and what it converges to is a well-known game theory equilibrium.
